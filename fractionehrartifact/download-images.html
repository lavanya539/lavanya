FractionEHR — Download All 81 Site Images

Permanently host all images on GitHub so they never expire

RECOMMENDED Method 1 — Python Script (downloads all in one go)

  1. Download the script: download_all.py
  2. Open Terminal / Command Prompt in the same folder
  3. Run: python3 download_all.py
  4. Wait ~30 seconds — all images save to a fractionehr-assets/ folder
  5. Upload the whole folder to GitHub → tell Claude "done, images uploaded"

ALTERNATIVE Method 2 — Browser Download

Downloads images one by one using fetch. May fail for expired URLs — run Method 1 instead if errors appear.

After uploading to GitHub: Tell Claude "done, images uploaded" and all 81 URLs in the HTML will be permanently replaced in one commit.
